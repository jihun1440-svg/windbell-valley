THE MAKING OF WINDBELL VALLEY

작은 마을의 제작 이야기

풍경종 계곡 / Windbell Valley / 风铃溪谷는 따뜻한 손그림 분위기의 오리지널 마을 장면입니다. 특정 작품의 인물이나 배경을 가져오지 않았습니다.

한 장의 그림에서, 살아 있는 마을로

마을 배경과 인물 4종은 OpenAI 이미지 생성 도구로 새로 제작했습니다. 인물마다 네 장의 걷기 포즈를 투명 스프라이트로 분리하고, 길의 연결 관계에 맞춰 이동시켰습니다. 배경 위에 물빛, 날리는 꽃잎, 새, 흔들리는 풍경종을 별도 레이어로 합성했습니다.

상점과 원경을 뒤에 두고 인물과 동물을 앞에서 움직이는 구성은 aldegad / sprite-gen의 village-scene.gif에서 참고했습니다. 원본 GIF는 이 사이트의 공개 소재에 포함하지 않았습니다. 사용자가 제시한 이전 저장소 주소는 확인 당시 404였고, 현재 sprite-gen 저장소에서 해당 파일을 확인했습니다.

바람이 남긴 선율

배경음악 〈개울에 남긴 인사〉는 이 장면을 위해 새로 작곡한 36초의 연주곡입니다. 오음 음계의 플루트 선율, 튕기는 현의 반주, 풍경종과 개울의 잔잔한 소리를 코드로 합성했습니다. 외부 음악이나 음원 샘플을 사용하지 않았습니다.

한국어 단편 영상

웹에서 사용하는 배경·스프라이트·움직임을 동일한 렌더러로 합성한 36초 영상입니다. 1920×1080, 24fps, H.264 영상과 AAC 스테레오 음악으로 제작했습니다. 한국어 자막은 영상에 직접 들어 있어 다운로드해도 남습니다. 음성 내레이션 없이 음악과 자막으로 감상하는 작품입니다.
